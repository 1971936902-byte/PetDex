# 证据目录与采集文件说明

## 1. 证据使用原则

原始采集材料只用于理解竞品结构，不用于直接复制 UI、素材、品牌或文案。

可靠性等级：

- A：可作为页面结构/状态参考。
- B：可作为辅助参考，需要结合文本校验。
- C：存在遮挡、误切或复现性质，只能说明特定状态。
- D：无效或不建议使用。

## 5. 采集结论

确认真实逻辑：

- 页面为单页应用，通过 hash 和 `pageView` 切换。
- 云养广场是特殊沉浸页，会隐藏顶部导航。
- 定制方案页不直接支付，只跳转工作台。
- 支付页在工作台内部 `pay` phase。
- 微信支付禁用，支付宝可用。
- 支付二维码有倒计时、订单卡和检查状态按钮。
- 工作台内部存在多阶段状态机。

待进一步验证：

- 真实订单创建返回结构。
- 真实支付回调。
- 支付成功后动作生成耗时。
- `.petpack` 文件格式。
- 客户端真实导入行为。
- 云养广场加入、点赞、投喂接口。
