# 风险登记册

## 1. 高优先级风险

| 风险 | 等级 | 说明 | 应对 |
| --- | --- | --- | --- |
| 生成不像 | 高 | 用户最核心的购买理由是“像我家宠物” | 多候选、可重试、人工精选、局部微调 |
| 付款后无法交付 | 高 | 会导致严重客诉 | 订单状态、任务队列、失败补偿、人工客服 |
| 客户端安装失败 | 高 | 直接影响产品闭环 | Windows 优先、签名、安装指南、托盘验证 |
| 复制竞品素材/文案 | 高 | 法务和品牌风险 | 自有品牌、原创素材、原创文案 |
| 用户照片隐私 | 高 | 涉及个人和宠物照片 | 隐私政策、删除机制、最小存储 |
| 支付重复下单 | 高 | 造成退款和后台脏订单 | 前端锁、后端幂等、订单取消 |

## 2. 中优先级风险

| 风险 | 等级 | 说明 | 应对 |
| --- | --- | --- | --- |
| 生成耗时长 | 中 | 用户等待焦虑 | 进度条、任务恢复、通知 |
| 艺术相册范围膨胀 | 中 | 会拖慢主链路 | P2 后置 |
| 云养广场性能压力 | 中 | 多宠物动效和同步复杂 | 先做只读展示 |
| macOS 安全提示 | 中 | 未签名会被拦截 | 先 Windows，后签名 macOS |
| 内容侵权 | 中 | 上传明星/动漫/他人照片 | 上传协议、审核、举报 |
| 客服压力 | 中 | 支付、安装、生成问题多 | FAQ、订单号、客服后台 |

## 3. 低优先级风险

| 风险 | 等级 | 说明 | 应对 |
| --- | --- | --- | --- |
| UI 与竞品过像 | 低到中 | 用户感知和法务风险 | 自有视觉体系 |
| 多端适配不足 | 低 | 初期用户集中桌面端 | 先保证 1440px 和移动端基础可用 |
| 社区冷启动慢 | 低 | 云养广场早期没内容 | 使用官方精选宠物填充 |

## 4. 上线前必须解决

- 自有品牌和原创素材。
- 生成失败补偿机制。
- 支付状态可追踪。
- 客户端能真实导入。
- 隐私政策。
- 用户协议。
- 禁止上传侵权素材说明。
- 客服联系方式。
