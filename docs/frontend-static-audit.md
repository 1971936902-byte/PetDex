## 核心口径

- 项目仓库名保留 `PetDex`，页面产品口径使用自有品牌 `伴生造物 / MyPet Studio`。
- 原始截图只作为结构和状态参考，不复制竞品域名、素材、下载链接和完整文案。
- P0 主链路优先：首页 -> 上传 -> 候选生成 -> 选择候选 -> 套餐 -> mock 支付 -> 动作生成 -> 宠物码 / `.petpack` -> 客户端下载。
- 艺术相册和云养广场在当前前端中作为增长试验展示，不作为 MVP 核心交付承诺。

## 后续真实化缺口

- 前端已接入本地 Flask API，上传、候选生成、订单、mock 支付、动作包、作品库和 `.petpack` 下载链路已跑通。
- 当前支付仍是 mock 支付，真实上架前需要接支付通道、回调验签、订单对账和退款处理。
- 需要真实桌面客户端承接 Windows 导入、托盘退出和基础动作播放，下载页目前保留安装包接入位。
- 需要正式素材授权条款、隐私政策、退款规则和用户主动删除入口后再公开上架。
- 轻量模型可完成 MVP 闭环，但生产级动作质量仍需要更稳定的图像分割、姿态控制和人工兜底流程。

## 2026-06-12 客户视角补充整改
